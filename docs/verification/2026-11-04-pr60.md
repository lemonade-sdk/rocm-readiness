# PR #60 producer mapping verification

The production policy discovers the greatest numeric ROCm version in current
stable qualification evidence, then selects up to two distinct newer minor
tracks in current nightly qualification evidence. Within one minor track the
newest numeric SDK version is selected. Producer numeric versions remain unchanged
(for example `10.3.0`); the complete alpha/date SDK is retained separately.
Every readiness collection rebuilds from current producer snapshots. Previous
published records are used only for publication recovery and upstream health.
