# Dashboard UI

- Follow the [Signal Deck design language](../docs/ui-design-reference.md) for UI changes in this directory. Use the [Signal Deck interface skill](../.agents/skills/signal-deck-interface/SKILL.md) when designing or reviewing those changes.
- Reuse shared theme tokens and interaction patterns. Preserve the documented palette unless the user requests a design-language change.
- For visual changes, check the affected views in light and dark themes at narrow and wide widths. Follow the [UI verification commands](README.md).
